The header is the only global control surface. Left to right:

ControlWhat it does
Page tabsHierarchy, Chronology, Where time goes, Metrics, Maintenance, Help. The count on Hierarchy is the number of rows passing the current filters.
Shown / totalRows in scope versus rows in the database — the fastest way to tell a filter is still on.
CSV · JSONExport the rows currently in scope, columns verbatim from the table.
RefreshRe-read the open file. On the demo dataset it just restamps the note.
Data sourceStatus dot plus a menu: open a file, toggle auto-poll, save a copy of the database.
?This guide — the same page as the Help tab.

Status dot: accent means a real database is loaded, grey means demo data, red means the last file could not be read — the menu shows the error.
