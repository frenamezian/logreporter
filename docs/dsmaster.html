What clicking does, shell-wide:

  • A page tab — swaps the content region only. Filters, drill scope, tree open/closed state and the selected entry all survive, so switching pages is a change of lens, never a reset.
  • A tree node — single click sets the drill scope (and writes the breadcrumb); double click does that and collapses the node. An agent leaf toggles.
  • A breadcrumb — truncates the drill to that depth. All repos clears it.
  • A filter or chip — recomputes rows in scope; the header count and every page follow within the same frame.
  • Any entry row, anywhere — selects it and opens the detail panel; the content region reflows narrower rather than being overlaid, and dense row grids drop their optional columns.
  • The « rail button — collapses the left panel to a 46px rail carrying just the filter badge; the filter icon restores it with filters open.
  • ? — opens the Help page. It is a page like any other: the header, the left panel and the breadcrumb stay put, and the tab you came from is one click away.

Only one element scrolls per page: the content region. Header, breadcrumb and legend rows are fixed so the columns you are reading against never leave the screen.
