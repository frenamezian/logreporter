The default page: one card per repository, nested down through branches, tasks and finally the individual log entries.

Every level carries the same summary vocabulary — a stacked bar showing how its wall-clock time splits into activity, issue, decision, GitHub and idle, then the wall-clock total and the idle share. Badges count logs and issues. Time → jumps to Where time goes already scoped to that node.

Task rows list entries in ascending time with type, agent, title, a description snippet and level. Clicking a row opens the detail panel on the right; the row grid drops to time / type / entry while the panel is open so nothing is truncated.

Expand all and Collapse all act on the rows in scope only — the navigation tree keeps its own open state.
