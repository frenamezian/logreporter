The left panel holds two collapsible sections: Filters and Navigation. Both narrow what every page shows.

Filters are a flat AND of search text, repository, branch, agent, log type, git action, level, status, priority and a date range. Each active filter appears as a chip you can dismiss; the count next to the section title tells you how many are on even when the section is collapsed.

Navigation is the repository → branch → task → agent tree. A single click scopes the whole dashboard to that node and writes it into the breadcrumb; a double click scopes it and collapses the node so you keep your place. Clicking an agent toggles that agent on and off within its task.

The tree is deliberately built from the filtered set before your drill scope is applied, so every sibling stays visible and one click away — you never have to walk back up the breadcrumb to move sideways. All repositories clears the drill; the breadcrumb above the content does the same at any depth.

The « button collapses the panel to a rail; the filter icon on the rail brings it back with the filter section open.

On this Help page the same panel carries the guide's outline instead — filters have nothing to narrow here. The field at its top searches the whole guide, headings and prose alike: topics that only match in the body are marked in text, the count under the field says how much of the guide matched, and Escape or Clear restores the full outline.
