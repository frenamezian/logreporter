Click targetResult
A delete-scope fieldRecomputes the match count immediately. This scope is independent of the page filters — deletion must be stated explicitly, never inherited from whatever you were browsing.
Delete N logsOpens the confirmation dialog restating the count and how many repositories it touches. No deletion happens yet.
ConfirmRemoves the rows from the in-memory database and the row array. Every page updates; the note tells you to save a copy to persist. The file on disk is untouched.
Export CSV / JSONWrites the rows in the current filter and drill scope, columns verbatim — the opposite scoping rule to delete, which is why the two live in separate cards with separate labels.
Save database copyExports the mutated database bytes as a download. The only way a deletion becomes permanent.
