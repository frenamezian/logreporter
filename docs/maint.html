Logs are retained until you delete them — there is no automatic rotation, on purpose.

Delete takes its own scope (repository, branch, older-than date, log type) that is independent of the page filters, shows how many rows match, and asks for confirmation before removing them. Rows are deleted from the database held in memory; use Save database copy to write the shrunken file back out. Nothing on disk changes until you save.

Export honours the page filters and drill scope instead, so you can carve out one branch or one date range as CSV or JSON.

The stored volume table is the only view that always reads the entire database: rows and issue counts per repository and branch with the oldest and newest timestamps, so you can see what is worth pruning.
