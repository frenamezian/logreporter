LogReporter is a single static page that reads an agent activity log — a SQLite file, activity_logs.db — directly in your browser. There is no server and no upload: the file is parsed in place and every view is computed from the rows in memory.

On first load you are looking at the bundled demo dataset, so every page has something in it. To read your own log:

  1. Open the data-source button in the header — it reads Demo data until a file is loaded.
  2. Choose Open activity_logs.db and pick your file (.db, .sqlite, .sqlite3).
  3. The status dot turns accent-coloured and the row count appears. Every page now reflects your data.
  4. Turn on Auto-poll if agents are still writing — the file is re-read whenever its modified time changes.

Auto-poll needs a browser that supports file handles (Chromium-based). Elsewhere, press Refresh and re-pick the file.

A good first pass: leave the filters empty, skim Hierarchy to see which repositories carry the work, then hit Where time goes to see how much of that wall-clock time was idle.
