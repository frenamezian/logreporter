Level selection

There is no level control: the level is the drill depth. No drill → repositories; drill.repo → its branches; drill.branch → its tasks; drill.task → the runs of that task, at which point the waterfall and gaps table appear. That is why the breadcrumb and the tree are the only way back up — nothing here can fall out of sync with them.

Bars

Each bar is stacked activity → issue → decision → GitHub → idle, scaled against the largest wall clock in view, and then subdivided by whatever makes it up: the branches of a repository, the tasks of a branch, the agents of a task, the individual log rows of a run, each with a hairline between neighbours. Category order is unchanged by the subdivision, so the bar still reads the same way; the hairlines only reveal that a block is several things.

Subdividing must never change a bar's length, and it does not: a parent's category total is an apportioned figure while its children carry raw per-run sums (which double-count nesting), so the children are scaled onto the parent's total before being drawn. Idle has no child that owns it and stays a single block.

Trace highlighting

With an entry open, every waterfall segment sharing its trace_id keeps a lit treatment and the open one is outlined; the legend says so in words. This is what makes Prev / Next in trace in the detail panel legible — the trace stays lit while the outline moves along it. Because selectLog follows a trace into another task, the drill can move under you here, and the waterfall follows rather than being left behind.

Details that matter when reading the waterfall

  • Indentation is agent_path depth, not nesting in time. Horizontal position is real wall clock, against a five-tick axis spanning the task.
  • A zero-length segment — the closing end row, or two rows sharing a timestamp — is drawn as a tick so it stays visible and clickable. A tick landing on the closing edge is pinned to the right edge, because the bar clips its children.
  • OWN reads "—" for a run with no subagents; there is nothing to subtract, so repeating the span would only be noise.
  • The IDLE row shares the same horizontal frame, so a gap lines up with the runs on either side of it.
