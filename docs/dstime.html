Click targetResult
A bar rowDrills one level deeper and re-renders this page at that level: repositories → branches → tasks → agents. Nothing else on screen moves.
Breadcrumb / treeThe way back up. The page's level is always exactly the drill depth — there is no separate level control to fall out of sync.
An agent bar (deepest level)Toggles that agent as a filter within the task, so the waterfall and stats narrow to its runs.
A waterfall rowSelects that run's opening entry and opens the detail panel — the bridge from "this agent took 22 minutes" to what it actually did.
A gaps-table rowDrills to the repository, branch and task of that gap, which brings up its waterfall below.

Bar segments are always ordered activity → issue → decision → GitHub → idle, so the same visual position means the same category on every row of every level.
