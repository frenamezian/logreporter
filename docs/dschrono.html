Click targetResult
Entry blockSelects it and opens the detail panel — the fastest route from "something happened here" to the full record and its trace.
Newest / Oldest firstReverses the stream. Day headers and idle rows are recomputed, not merely flipped.
Idle rowInert by design. It is evidence, not a destination; drill to the task in the tree if you want its waterfall.
Any filter or drill changeRebuilds the stream, including which gaps count as idle — narrowing to one agent does not invent idle time for the others, because gaps come from the task model.

The stream renders the first 500 rows in scope and says so in the header row when it truncates.
