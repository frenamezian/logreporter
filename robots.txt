# robots.txt is only honoured at the root of an ORIGIN. This site is published
# on a shared origin — frenamezian.github.io — where a project page lives under

# real robots.txt the moment this site moves to a custom domain (a CNAME file in
# this branch), which is when getting it wrong would matter. Nothing here relies

# and the same permissions are restated in llms.txt.
#
# The policy is: everything is open. This is an MIT-licensed open source project
# whose whole problem is that nobody knows it exists. Search crawlers, AI
# training crawlers and live retrieval agents are all welcome. The AI agents are
# named explicitly rather than left to the wildcard, so the intent survives
# someone later pasting in a stock blocklist.
