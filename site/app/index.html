The demo is not in this clone

You are looking at a placeholder. The live demo is a full copy of the dashboard, exported from a commit at publication time — build output rather than source, so it is not in the repository.

Run the real thing instead

You have the dashboard already; it is the repository you cloned. From its root: 

python seed/new_db.py     # or: bash seed/init_db.sh, for 148 sample rows
python serve.py           # then open http://127.0.0.1:8250/index.html

It has to be served over http://. Opened as a file, the browser's fetch() cannot read the database and the page falls back to demo data without saying so.

Or build the site locally

python site/build.py      # then open site/_build/app/index.html

That exports the dashboard from HEAD into site/_build/app/, alongside a synthetic sample database — the same thing the published demo is.

The published copy lives at frenamezian.github.io/log_reporter/app/.
