The default page: one card per repository, nested down through branches and tasks to the individual log entries.

The summary each level carries

Repository, branch and task rows all show the same four things to the right of the name:

  • A count and the wall-clock total — "1 branches · 1h 31m" for a repository, "1 tasks · 1h 31m" for a branch, "24 entries · 1h 31m · 4 agents" for a task. Where any of that time was idle, the idle share follows as a percentage.
  • A stacked bar — how that wall-clock time splits into activity, issue, decision, GitHub and idle, always in that order, so the same position always means the same category. The bar is scaled to the row's own total, so it reads as a composition rather than a comparison against its neighbours.
  • Badges — the number of log rows, and the number of issues in red when there are any.
  • Time → — drills to that repository, branch or task and switches to Where time goes. The one cross-page jump on this page.

Entry rows

Opening a task lists its entries in ascending time — you read a task the way it happened — as Time, Type, Agent, Entry, Level. The entry column carries the title followed by a dimmed snippet of the description. Clicking a row opens it in the detail panel on the right; the selected row keeps an accent left border so you do not lose it while reading the panel.

Entry rows are rendered the first time a task is opened, not up front, so a file with thousands of rows still expands instantly.

Opening and closing

ActionResult
Click a repository, branch or task rowToggles it open or closed in place. Scroll position is kept and nothing else on the page changes.
Double-click oneAlways ends collapsed — useful for closing a level you opened by accident.
Expand allOpens every repository, branch and task holding a row in the current scope. Not the whole database — only what you are looking at.
Collapse allCloses everything here. The navigation tree in the sidebar keeps its own, independent open state.

Drilling from the sidebar or the breadcrumb auto-expands the path you drilled to, once. After that the rows stay where you put them: re-applying the drill on every re-render would spring open a row you had just closed by hand.
