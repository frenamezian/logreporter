The idle row names the repository, branch and task that went quiet, which is usually enough to explain the gap without opening anything.

Click targetResult
Entry rowSelects it and opens the detail panel — the fastest route from "something happened here" to the full record and its trace.
Newest first / Oldest firstReverses the finished stream, headers and idle rows included, so they stay attached to the right entries instead of being flipped into the wrong place. Re-rendering only; the scope is untouched.
Idle rowInert by design. It is evidence, not a destination; drill to the task in the tree if you want its waterfall.
Any filter or drill changeRebuilds the stream, including which gaps count as idle. Narrowing to one agent does not invent idle time for the others, because gaps come from the task model rather than from the spacing of the visible rows.

Implementation notes

  • stream(inScope, model) emits day, gap and log rows ascending; the component reverses the array for newest-first, which is the default.
  • A gap row is emitted only between two consecutive rows of the same task, and only when the model has a gap starting exactly at the earlier row's timestamp.
  • The cap is 500 stream rows, not 500 log rows — day headers and idle rows count against it. The line above the table reads "N rows" normally and "Showing 500 of N rows" when it truncates; the legend's count is always the number of entries in scope.
