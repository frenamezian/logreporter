One flat stream across everything in scope, so interleaved agents read in the order they actually ran rather than grouped by who wrote them.

What is in the stream

Three kinds of row are interleaved:

  • Entries — one per log row, with a coloured dot for its type and a dimmed snippet of the description after the title. Clicking one opens it in the detail panel.
  • Day headers — the date, inserted wherever the day changes.
  • Idle rows — Idle 41m · repo/branch · task, inserted between two consecutive entries of the same task when no agent was running between them. They come from the task time model, not from the spacing of the rows on screen, which is why narrowing to one agent does not invent idle time for the others.

The idle rows are the point of this page: the silence is as legible as the activity, and it is labelled with the branch and task that went quiet, which is usually enough to explain it without opening anything.

Order and the row cap

The stream is built in ascending time and then reversed for Newest first, which is the default — so day headers and idle rows stay attached to the right entries in both directions rather than being flipped into the wrong place. Oldest first reads it as it happened.

The legend strip counts the entries in scope. The line above the table says how many rows the stream has; past 500 it renders the first 500 and says so. Narrow the filters or drill down if you hit that ceiling.
